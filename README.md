# Descomplicando Kubernetes

This repository contains my hands-on studies and practical labs focused on understanding Kubernetes fundamentals and orchestration concepts.

## 🚀 Objectives

- Learn and practice Kubernetes core concepts
- Understand cluster architecture and workload orchestration
- Improve skills for DevOps / SRE and Cloud Infrastructure roles

## 🧩 Topics Covered

- Kubernetes architecture (master / worker nodes)
- Pods, ReplicaSets and Deployments
- Services and basic networking
- ConfigMaps and Secrets
- Volumes and persistent storage
- Scaling and self-healing concepts
- Basic troubleshooting and debugging

## 🛠 Tools & Technologies

- Kubernetes (kubectl, manifests)
- Docker
- YAML
- Linux
- Git

## 📌 What you will find here

- Step-by-step labs and exercises
- Example manifests and configurations
- Notes and experiments from my learning process
- Basic automation and operational practices

## 🎯 Goal

This project is part of my continuous learning path to strengthen my skills as a **DevOps / Site Reliability Engineer (SRE)**, focusing on reliability, scalability and cloud-native infrastructure.

## 📚 Learning Source

Hands-on labs and studies based on the **"Descomplicando Kubernetes"** course by **LinuxTips**, taught by **Jeferson Fernando**, a recognized Kubernetes and DevOps expert in the cloud-native community.
